# 火柴棒等式谜题技能

## 核心规则

- **移动一根火柴**：从等式中的一个数字取走1根火柴，加到另一个数字上
- **总数不变**：移动前后火柴棒总根数保持不变
- **只改两个数字**：源数字失去1段，目标数字得到1段，用的是**同一根火柴**

## 七段数码管

```
  段1(上横)
段2  段3
  段4(中横)
段5  段6
  段7(下横)
```

数字0-9：0(6段), 1(2段), 2(5段), 3(5段), 4(4段), 5(5段), 6(6段), 7(3段), 8(7段), 9(6段)

## 有效的单根移动变换

| 错误→正确 | 段移动  | 说明         |
| --------- | ------- | ------------ |
| 8→0       | 移除段4 | 8去中横变0   |
| 8→6       | 移除段3 | 8去右上竖变6 |
| 8→9       | 移除段5 | 8去左下竖变9 |
| 9→5       | 移除段3 | 9去右上竖变5 |
| 9→3       | 移除段2 | 9去左上竖变3 |
| 6→5       | 移除段5 | 6去左下竖变5 |
| 7→1       | 移除段1 | 7去上横变1   |

**反向**（添加1根）：0→8, 1→7, 3→9, 5→6, 5→9, 6→8, 9→8

## 使用方法

### 生成题目

运行脚本生成题目：

```bash
python3 skills/matchstick-puzzles/scripts/generator.py 20
```

输出格式：

```
第1题
  错误等式: 8-1=9 ❌
  正确答案: 9-1=8 ✅
  解法: 把结果第1位的8的左下竖移到第1个数第1位的9上
```

### 解答用户的谜题

用户给出错误等式 → 分析移动哪根火柴能使其成立：

1. 找出数学上正确的等式（目标）
2. 确定需要变换的数字对
3. 验证变换是否只用1根火柴且总数不变

### 验证谜题

用generator.py的verify_puzzle函数检查谜题是否有效。

## 重要约束

- ❌ 不能移动两根火柴改变一个数字
- ❌ 不能改变运算符（+变成-）
- ❌ 不能移动火柴到运算符上
- ✅ 同一根火柴从A移到B，总数不变
- ✅ 变换必须是上述7种有效变换之一
