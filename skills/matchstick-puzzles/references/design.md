# 火柴棒等式谜题设计手册

## 核心规则

1. **移动一根火柴**：从等式中的一个数字取走一根火柴，加到另一个数字上
2. **总数不变**：移动前后，整个等式的火柴棒总根数保持不变
3. **只改一个数字**：每次只能改变等式中的一个数字的火柴棒配置

## 七段数码管基础

```
  段1(上横)
段2  段3
  段4(中横)
段5  段6
  段7(下横)
```

## 设计原理

### 从正确等式出发生成错误等式

1. **选择正确等式**：数学上成立的简单等式
2. **确定移动源(A)**：选择一个数字，它需要移除1根火柴变成另一个数字
3. **确定移动目标(B)**：选择另一个数字，它需要添加1根火柴变成另一个数字
4. **验证**：
   - A和B使用的段必须相同（一根火柴）
   - 错误等式必须数学上不成立
   - 正确等式必须数学上成立
   - 移动前后火柴棒总数不变

### 有效的变换模式

**"9"相关变换**（最常用）：

- 9→3：移除左上竖，3+?=?
- 9→5：移除右上竖，?+5=?或?+?=?

**"8"相关变换**：

- 8→0：移除中横，变为0
- 8→6：移除右上竖，变为6
- 8→9：移除左下竖，变为9

**"7"相关变换**：

- 7→1：移除上横，变为1

**"6"相关变换**：

- 6→5：移除左下竖，变为5

### 推荐等式模板

```
# 简单（适合低年级）
1+1=2, 7+1=8, 3+3=6, 8-4=4, 6+5=11

# 中等（两位数）
15+1=16, 10+7=17, 25+1=26, 30+6=36
12+7=19, 18+1=19, 41+1=42, 50+5=55

# 困难（减法得9）
10-1=9, 16-7=9, 19-10=9, 28-19=9
37-28=9, 55-46=9, 73-64=9, 86-77=9

# 挑战
9+9=18, 7+7=14, 3+8=11, 6+9=15
5+9=14, 8+9=17, 15-6=9, 24+6=30
```

## 验证清单

生成一道题后，务必验证：

1. ✅ 正确等式数学成立（2+3=5 ✓）
2. ❌ 错误等式数学不成立（2+3=6 ✗）
3. 🔢 移动前后火柴棒总数不变（12根→12根）
4. 🎯 移动的段在A移除，在B添加，是同一根火柴

## 常见错误

1. **火柴数变化**：生成前后总数不一致
2. **无效变换**：尝试了不存在的一根火柴变换
3. **数学巧合**：错误等式恰好也成立
4. **描述不清**：没说明从哪个数字的哪根移到哪个数字

## 难度分级

| 难度 | 特征                 | 示例             |
| ---- | -------------------- | ---------------- |
| 简单 | 个位数运算，结果<10  | 1+1=2, 7-3=4     |
| 中等 | 两位数加法，结果十几 | 15+1=16, 30+6=36 |
| 困难 | 减法得9，或进位复杂  | 28-19=9, 99-90=9 |
| 挑战 | 多位数，结果>99      | 29+70=99         |
