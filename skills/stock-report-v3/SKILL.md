2. 点击 "财务报表" 标签页

## 成长可持续性分析 (V4新增)

### 必须分析的内容

1. **营收增长驱动因素**:
   - 内生增长：产品销量增长
   - 外延增长：并购、新产品
   - 价格增长：提价能力

2. **净利润增长质量**:
   - 是否快于营收增长（规模效应）
   - 是否来自主营业务（vs非经常性损益）

3. **可持续性判断**:
   - 行业空间是否足够大
   - 竞争格局是否稳定
   - 公司壁垒是否可持续

### 成长性评分标准

| 指标          | 优秀 | 良好   | 一般  | 差       |
| ------------- | ---- | ------ | ----- | -------- |
| 营收3年CAGR   | >20% | 10-20% | 5-10% | <5%      |
| 净利润3年CAGR | >25% | 15-25% | 5-15% | <5%      |
| 净利率趋势    | 上升 | 稳定   | 下降  | 大幅下降 |

## 现金流详细分析 (V4新增)

### 必须分析的内容

1. **经营现金流vs净利润**:
   - 比率 > 1: 优秀（净利润转化为现金能力强）
   - 比率 0.8-1: 良好
   - 比率 < 0.8: 需关注

2. **现金流肖像**:
   - "妖精"型：经营+，投资+，筹资-（扩张期）
   - "老母鸡"型：经营+，投资-，筹资-（成熟期）
   - "赌徒"型：经营-，投资+，筹资+（转型期）
   - "烧钱"型：经营-，投资+，筹资-（危险）

3. **自由现金流**:
   - FCF = 经营现金流 - 资本支出
   - FCF > 0: 能够持续分红和再投资
   - FCF < 0: 需要外部融资支撑

### 现金流评分标准

| 指标              | 优秀       | 良好     | 一般     | 差       |
| ----------------- | ---------- | -------- | -------- | -------- |
| 经营现金流/净利润 | >1.2       | 1.0-1.2  | 0.8-1.0  | <0.8     |
| 自由现金流        | >0         | =0       | <0       | 持续<0   |
| 筹资活动现金流    | 流出或持平 | 少量流入 | 大量流入 | 大量流入 |

## 多估值模型 (V4新增)

### DCF估值（详细版）

```python
# DCF估值参数
growth_rate = 0.05  # 永续增长率
discount_rate = 0.10  # 折现率
net_profit = X  # 当前净利润
shares = X  # 总股本

# 估算内在价值
intrinsic_value = net_profit * (1 + growth_rate) / (discount_rate - growth_rate)
per_share_value = intrinsic_value / shares
```

## 巴菲特指标修正规则 (重要!)

当投资收益占比过高时，需要对巴菲特10大公式进行修正:

### 投资收益占比判定标准

| 投资收益/净利润占比 | 风险等级 | 修正措施              |
| ------------------- | -------- | --------------------- |
| < 10%               | 低风险   | 无需修正              |
| 10% - 30%           | 中风险   | 扣0.5分/项            |
| 30% - 50%           | 高风险   | 扣1分/项              |
| > 50%               | 极高风险 | 扣2分/项,建议下调评级 |

### 需要修正的指标

1. **ROE修正**: 如果投资收益占比>30%，ROE得分扣1分
   - 原因: ROE可能被投资收益虚高

2. **盈利稳定性修正**: 如果投资收益占比>20%，盈利稳定性扣1分
   - 原因: 投资收益波动大，不稳定

3. **自由现金流修正**: 如果交易性金融资产占比>40%，自由现金流扣1分
   - 原因: 大额理财占用现金流，可能影响主业

4. **资本配置(分红)修正**: 如果主营业务利润为负，分红得分归零
   - 原因: 用投资收益分红不可持续

5. **营业利润率修正**: 如果投资收益占比>30%，营业利润率得分扣1分
   - 原因: 营业利润被投资收益稀释

### 核心利润占比计算

```
核心利润 = 净利润 - 投资收益 - 公允价值变动收益 - 营业外收支
核心利润占比 = 核心利润 / 净利润
```

### 评级调整规则

当投资收益占比过高时，投资建议需要额外调整:

- 投资收益占比 > 30%: 建议下调一级 (如从⭐⭐⭐⭐下调为⭐⭐⭐)
- 投资收益占比 > 50%: 建议下调二级
- 核心利润为负: 直接标记为"不推荐"，需说明"依赖投资收益"
