# Eval 3: 角色不一致问题排查 - 技能执行记录

## 用户请求

"为什么我生成的视频里，每一幕的猫咪看起来都不一样？"

---

## 执行过程

### Step 1: 诊断问题

根据 Common Issues 表格中的描述，这个问题很明确：

**问题识别：** 每个场景独立生成 → 缺少角色参考 → 角色外观不一致

### Step 2: 按照技能提供解决方案

#### 根本原因分析

```
没有角色参考 → 每个场景的 img prompt 只描述角色 →
AI 每次重新想象角色外观 → 品种/颜色/服装都可能变化
```

**技能中的问题案例：**

- 场景0：橙色小猫，戴小帽子，站在山顶
- 场景1：灰色猫在森林里走（品种变了！）
- 场景3：白猫面对巨龙（颜色变了！）

#### 解决方案

**方案 A: 重新开始（推荐）**

```bash
# 1. 提取或重新设计角色描述
# 包含：物种、颜色、服装、配饰、表情、体型/年龄

# 2. 生成角色参考图（三视图）
python3 ~/.moltbot/skills/minimax-video-creator/scripts/generate_assets.py \
  --generate-character \
  --character-prompt "你的详细角色描述" \
  --output ./public

# 3. 重新生成所有场景图（使用 img2img）
python3 generate_assets.py \
  --script-json ./public/script.json \
  --character-ref ./public/character/character_reference.jpg \
  --output ./public
```

**方案 B: 修补（如果已有部分场景正确）**

编辑 script.json 中所有场景的 image_prompt，确保都包含：

```
"The [动物种类] (from reference) [动作/场景]"
```

并传入 `--character-ref` 参数重新运行。

#### 角色一致性规则（5条）

1. **必须先生成角色参考，再生成任何场景图**
2. **所有场景图必须使用 img2img（image_url 参数）**
3. **角色描述必须包含：** 物种、颜色、服装、配饰、表情、体型/年龄
4. **场景提示词格式：** `[参考图中的角色] + [动作/姿态] + [场景] + [风格关键词]`
5. **不要在场景间改变角色外观** — 如需不同服装，更新角色提示词并重新生成参考图
